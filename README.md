# Seoul Glow Maison — Shopify theme

A luxury Korean beauty + KAVO fashion theme for **seoulglowuae.com**. Bilingual (English / العربية with full RTL).

- `seoul-glow-maison-theme.zip` — ready to upload: Shopify Admin → Online Store → Themes → Add theme → Upload zip file.
- `theme/` — the source code.

## دليل سريع (عربي)

1. **رفع الثيم:** من لوحة شوبيفاي ← Online Store ← Themes ← Add theme ← Upload zip ← اختاري `seoul-glow-maison-theme.zip`.
2. **معاينة:** اضغطي Preview وجربي الموقع بالإنجليزي والعربي (زر «عربي» أعلى الصفحة).
3. **النشر:** إذا عجبك اضغطي Publish.
4. **واتساب:** Theme settings ← Commerce ← اكتبي رقم الواتساب (مثال 9715XXXXXXXX) ليظهر الزر العائم.
5. **السوشيال:** Theme settings ← Social ← روابط انستقرام وتيك توك وسناب.
6. **الصور:** صور الهيرو والقصة وKAVO موجودة في Files باسم `sg-maison-*` ويمكن تغييرها من محرر الثيم.
